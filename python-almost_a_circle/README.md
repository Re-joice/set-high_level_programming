# Python - Almost a Circle

This project is part of the Python programming course.

The project focuses on:

- Unit testing
- PEP 8 validation
- Classes and objects
- Inheritance
- Private attributes
- Getters and setters
- Serialization and deserialization
- JSON handling
- File handling
- `unittest` framework

## Testing

All classes and methods are tested using Python's `unittest` framework.

Tests can be run with:

```bash
python3 -m unittest discover tests
