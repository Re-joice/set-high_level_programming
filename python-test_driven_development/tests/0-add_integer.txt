The ``add_integer`` function
============================

Using ``add_integer``:

>>> add_integer = __import__("0-add_integer").add_integer

It adds two integers.

>>> add_integer(1, 2)
3

>>> add_integer(100, -2)
98

The second argument defaults to 98.

>>> add_integer(2)
100

Floats are converted to integers.

>>> add_integer(100.3, -2)
98

>>> add_integer(1.9, 2.1)
3

A TypeError is raised when the first argument is invalid.

>>> add_integer(None)
Traceback (most recent call last):
...
TypeError: a must be an integer

A TypeError is raised when the second argument is invalid.

>>> add_integer(4, "School")
Traceback (most recent call last):
...
TypeError: b must be an integer
