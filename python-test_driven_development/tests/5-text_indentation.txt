The ``text_indentation`` function
=================================

>>> text_indentation = __import__("5-text_indentation").text_indentation

Print a simple sentence.

>>> text_indentation("Hello. World?")
Hello.
<BLANKLINE>
World?
<BLANKLINE>

Print text with a colon.

>>> text_indentation("Python: is fun.")
Python:
<BLANKLINE>
is fun.
<BLANKLINE>

Leading spaces after punctuation are removed.

>>> text_indentation("Hello.   World.")
Hello.
<BLANKLINE>
World.
<BLANKLINE>

The argument must be a string.
