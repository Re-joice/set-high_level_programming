# Python - Test Driven Development

## Description

This project introduces Test Driven Development (TDD) in Python. It focuses on writing functions that are fully documented, tested using doctests, and compliant with PEP 8 (pycodestyle).

## Learning Objectives

At the end of this project, you should be able to explain:

- Why Python programming is awesome
- What interactive tests (doctests) are
- Why tests are important
- How to write documentation for modules and functions
- How to create and run doctests
- How to handle exceptions properly
- How to write clean, readable, and maintainable code
- How to follow pycodestyle standards

## Requirements

- Ubuntu 20.04 LTS
- Python 3.8.5
- pycodestyle 2.7.*
- All files end with a new line
- All files are executable
- Modules, classes, and functions must have documentation
- No external modules unless explicitly allowed
